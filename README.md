# Netflix Data Analytics Project 🎬

An end-to-end Data Analytics project using **Python, SQL, Excel and an interactive dashboard**.

## Dataset
Netflix Movies and TV Shows dataset from Kaggle.

## Dataset Size
- **8,807 rows**
- **12 original columns**
- **6,131 Movies**
- **2,676 TV Shows**
- **0 duplicate rows**

## Tools
Python • Pandas • NumPy • Matplotlib • Seaborn • SQL • Excel • Plotly

## Workflow
Raw Data → Cleaning → EDA → Python → SQL → Excel → Dashboard → Insights

## Main Analysis
- Movies vs TV Shows
- Release-year trends
- Content added over time
- Top genres
- Top countries
- Ratings
- Movie duration
- TV show seasons
- Missing and duplicate data

## Files
| File | Purpose |
