# # 🎬 Netflix Data Analytics Project

## 📌 Project Overview

This project performs an end-to-end **Data Analytics analysis of Netflix content** using Python, SQL, Excel, and Data Visualization.

The objective is to explore Netflix's movies and TV shows, clean and transform the raw dataset, identify meaningful trends and patterns, and present the findings through an interactive dashboard.

The project demonstrates the complete workflow followed by a Data Analyst:

**Raw Data → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Excel Analysis → Visualization → Dashboard → Business Insights**
